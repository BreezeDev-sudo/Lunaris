Lunaris Setup Tutorial

1. Invite Lunaris

Invite Lunaris to your Discord server, then make sure the bot has permission to view channels, send messages, embed links, attach files, read message history, manage messages, and use application commands.

2. Open The Dashboard

Go to the dashboard, log in with Discord, and select the server you want to configure. The dashboard is the main setup area because it has larger editors, previews, role search, channel search, and module pages.

3. Configure Channels

Open Channels. Set where scheduled events, live events, raid alerts, moderation logs, and logger output should post. If a command says a channel is missing, this is the first module to check.

4. Configure Roles

Open Roles for global permission roles, logger roles, moderation roles, admin roles, and auto roles. Administrators bypass normal role restrictions.

5. Configure Events

Open Events. Edit Schedule Event, Start Event, End Event, and Cancel Event. Event ping roles are in this module so you do not have to search through the global Roles page.

6. Configure Training

Open Training. Training has its own schedule, start, and end formats. In Discord, use /schedule-event type: Training or /start event type: Training when you want the training format.

7. Configure Raids

Open Raids. Raid commands are separate from Event and Training commands, so raids do not use the Event or Training type option.

8. Save And Test

Click Save Settings after changing channels or roles. After editing message formats, click Save Template. Test with one schedule command before using it in a real event.

Quick Setup Steps

  1. Invite Lunaris to your Discord server.
  2. Go to Dashboard and log in with Discord.
  3. Select the server you want to configure.
  4. Open Channels and choose where schedules, raids, events, logs, and logger output should post.
  5. Open Roles and choose who can use logging, moderation, event, raid, and admin tools.
  6. Open Events and edit event schedule/start/end/cancel formats.
  7. Open Training and edit training formats separately.
  8. Open Sticky if you want one or more channels to keep a pinned-style message near the bottom.
  9. Click Save Settings after changing a module.

Dashboard Modules

Events

Configure event channels, event ping roles, Schedule Event, Start Event, End Event, Cancel Event, popup questions, buttons, banners, and post formats.

Training

Configure training-specific schedule, start, and end formats. Training uses the Event command with the Training type option.

Raids

Raid commands are available and use separate raid formats. Raids do not use Event or Training type options.

Moderation

Configure moderation permissions, moderation output, and mass-ban tools.

Roles

Set logger roles, event ping roles, raid ping roles, moderation roles, admin roles, ending ping roles, and auto roles.

Channels

Set the channels used for scheduled posts, raid alerts, event posts, moderation logs, and logger output.

Sticky

Create named sticky messages per channel. Lunaris keeps the latest copy near the bottom and removes old copies when new messages arrive.

Command Reference

Setup

  • /settings opens the Discord setup panel for quick channel, role, format, banner, welcome, and division-name changes.
  • /rules posts the SEA Military rules panel. You can attach a custom banner when running it.
  • /help shows this command overview inside Discord.
  • /status checks whether Lunaris is online and responding.
  • /support gives the support server/help link.

Events & Training

  • /schedule-event creates a scheduled event post with attendance buttons. Use the type option for Event or Training.
  • /start event starts a scheduled event by ID, or starts an immediate Event/Training if no ID is selected.
  • /end event posts an ending announcement for an active Event or Training record.
  • /cancel cancels an active scheduled post by ID. It does not ping event or raid roles.
  • /log sends event or training log output to the configured logger channel.

Raids

  • /schedule raid creates a scheduled raid post with attendance buttons.
  • /start raid starts a scheduled raid by ID, or posts an immediate raid start if no ID is selected.
  • /end raid posts a raid ending announcement for an active raid record.
  • /cancel can cancel an active raid by ID. Cancel messages do not ping raid roles.

Moderation

  • /warn warns a user and stores the warning record.
  • /warns views or clears warning records for a user.
  • /mute mutes a user when the bot has permission to manage the target member.
  • /kick kicks a user from the server.
  • /ban bans a user from the server.
  • /unban removes a server ban.
  • /moderation-panel posts a button panel for common moderation actions.
  • /massmove moves everyone from one voice channel to another.
  • /mod-logs views stored moderation logs.

Mass Ban

  • /massban bans multiple provided users with one reason.
  • /updateseamassban refreshes the SEA ban list and bans everyone valid on it.

FAQ

Why do I need the website if there is a Discord /settings command?

The website has the full setup panel, larger editors, search boxes, module navigation, and preview tools. The Discord panel is kept smaller for quick changes.

Why is a command missing from a module?

Each module only shows commands it actually changes. Use Overview search if you need to find a command quickly.

Where do I set who can use /log?

Open the Roles module and edit Logger Roles. Administrators bypass role restrictions.

Where do event logs post?

Open the Channels module and set Logger Output.
